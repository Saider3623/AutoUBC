## Changes Made

### 1. Hardened Google Drive sync state and transport lifecycle
- **Files:** `lib/services/google_drive_sync_service.dart`, `lib/main.dart`
- **Changes:** Removed the temporary debug-server instrumentation; added an explicit `SyncStartupAction.error`; stopped treating Drive API failures as an empty cloud; validated access tokens; selected the newest backup when duplicate filenames exist; closed authenticated HTTP clients; reused the selected remote file metadata; made download stream cleanup and temp-file cleanup explicit; preserved validated atomic replacement and rollback; added account-scoped persisted baselines; surfaced startup sync errors to the user.
- **Revert:** Restore the previous sync service and remove the `SyncStartupAction.error` branch from `lib/main.dart`.

### 2. Persisted pending local sync state
- **File:** `lib/providers/app_provider.dart`
- **Changes:** Added a persisted `autoubc_pending_sync` marker, serialized sync/persistence queues, explicit `markSyncCompleted`, lifecycle-safe disposal, and pending-state recovery before loading cars.
- **Revert:** Remove `_pendingSyncKey`, `_persistenceQueue`, pending-state load/save methods, `markSyncCompleted`, and restore the previous timer/dispose/flush implementation.
