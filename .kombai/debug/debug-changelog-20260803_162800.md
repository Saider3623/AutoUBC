## Changes Made

### 1. Suppressed background sync-only provider notifications
- **File:** `lib/providers/app_provider.dart`
- **Change:** Changed `_setPendingSync` so durable pending-state transitions no longer call `notifyListeners()`.
- **Why:** Background upload completion changed the `AppProvider` state and rebuilt the entire `MainScreen`/`PageView`, causing a brief visible flicker several seconds after launch.
- **Revert:** Restore the `_disposed` guard and `notifyListeners()` call after assigning `_needsSync`.

### 2. Added regression coverage for silent sync completion
- **File:** `test/app_provider_sync_test.dart` (new)
- **Change:** Added a provider test verifying that `markSyncCompleted()` clears the durable pending marker without notifying the widget tree.
- **Why:** Keeps background sync bookkeeping decoupled from visual rebuilds.
- **Revert:** Delete `test/app_provider_sync_test.dart`.
